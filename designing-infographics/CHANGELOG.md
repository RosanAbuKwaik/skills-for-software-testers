# Changelog

## 1.0.0
First stable version, tested on real requests.
- One graphic, delivered in one folder: HTML with moving arrows, SVG, PNG, GIF, MP4, plan.md, README and checks.
- Input from a topic, a link or pasted text; the source is named on the graphic.
- Styles `clean` (ByteByteGo) and `sketch`; layouts `single` and `poster`.
- Brand palette asked once on the first graphic, then changed in plain words.
- Status colours: red for fail, green for pass, amber for wait, each with an icon or word.
- 13 rendered checks in `build.js`: page errors, canvas, text overlap, box overlap, canvas fit, box drawn once, steps visible without motion, legend, colour-only kinds, status colours, AI-looking orange, animation, plan (with number sources).
- The chat reply is five lines with clickable links.

## 0.1.0 to 0.9.0
Built step by step from tests: multi-format folder, plan.md, rendered checks, links in the reply, no PDF, one box per state, group labels on brackets, status colours, honest numbers, no AI-looking orange.
